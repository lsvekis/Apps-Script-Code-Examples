# 24. Export a Doc as PDF (Blob)

**What it does:** Returns a PDF blob for a doc file (for emailing/archiving).

**When to use it:** Attaching PDFs in email or saving to Drive.

## How to run
Call `docToPdfBlob('DOC_ID')` from another function. Requires Drive access.
