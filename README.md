# Google Apps Script — 50 Code Snippets (Working Examples)

This repo contains **50 Google Apps Script snippets**, each with:
- a short explanation
- working code (`Code.gs`)
- notes on how to run it

> **How to use:**  
> Open a Google Apps Script project (or a bound script in Sheets/Docs), then copy/paste the snippet's `Code.gs` into your project.
> Some snippets are **Sheets-bound**, **Docs-bound**, or **Web App** specific—each folder README tells you.

## Folder structure

Each snippet lives in: `snippets/NN-title/`
- `README.md` — what it does + how to run
- `Code.gs` — the code

## Quick tips

- **Triggers:** For `onOpen(e)` / `onEdit(e)`, installable triggers are optional; simple triggers work when bound to a container file and authorized.
- **Placeholders:** Some examples require you to replace placeholders like `PASTE_TEMPLATE_DOC_ID`.
